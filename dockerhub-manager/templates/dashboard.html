分配 Docker 环境
选择目标服务器后自动读取该服务器已下载镜像。
使用者可在自己的电脑执行 cat ~/.ssh/id_ed25519.pub 获取公钥。默认推荐公钥登录。
当前创建的登录用户默认授予 sudo 权限。密码不会保存到面板配置；如需设置 root 密码，可登录后执行 sudo passwd root。默认12345678
选择目标服务器后检查是否支持容器可写层磁盘上限。
选择目标服务器后读取 GPU 能力；启用后默认全选全部 GPU。
选择目标服务器后显示可用 GPU。
留空时自动从 32000-32199 选择空闲端口；手动填写时必须位于该范围且未被占用。
默认分配 5 个宿主机业务端口，宿主机端口自动分配到 32200-32999。
用于常见调试场景；会在容器启动参数中增加 `--cap-add SYS_PTRACE`。
宿主机端口由系统自动分配；这里只需要填写容器内端口。
选择目标服务器后显示可用目录。
每行一个挂载：宿主机路径|容器内路径|ro/rw。宿主机路径仍必须位于服务器已注册根目录下。
→ 连接命令与端口映射
