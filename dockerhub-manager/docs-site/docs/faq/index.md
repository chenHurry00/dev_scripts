# 常见问题

## 容器 SSH 登录失败

优先检查：

- SSH 命令是否正确
- 端口是否正确
- 容器是否处于运行状态
- 密码或公钥是否与分配员提供的一致

若仍然失败，向分配员提供：

- 容器名
- 使用者标识
- 报错信息

## 文件传输后容器内不可见

优先检查：

- 文件是否传输至挂载目录
- 容器内查看的路径是否为挂载点
- 文件是否实际上传至其他目录

## 服务端口无法访问

优先检查：

- 服务是否监听 `0.0.0.0`
- 使用的端口是否为分配的映射端口
- 容器内监听端口是否与映射规则一致

## GPU 设备不可见

优先检查：

- 容器分配时是否启用 GPU
- `nvidia-smi` 是否可执行
- 当前镜像环境是否满足 CUDA 需求

## 容器重建后环境变化

这通常为正常现象，因为容器系统层可能发生变化。

先确认：

- 重要数据是否仍在挂载目录
- 是否在重建前执行过手动备份镜像
- 是否更换了基础镜像

## 资源配额不足

不应自行判断平台配置失效，建议直接联系分配员并说明：

- 容器名
- 当前资源限制
- 具体报错或瓶颈表现
- 需要增加的资源类型
- 为短期需求还是长期需求
