# FAQ

## 登录不上容器怎么办

优先检查：

1. SSH 命令是否正确。
2. 端口是否正确。
3. 容器是否运行中。
4. 密码或公钥是否与分配员提供的一致。

如果仍然失败，向分配员提供：

1. 容器名。
2. 使用者标识。
3. 报错信息。

## 文件传了但容器里看不到怎么办

优先检查：

1. 文件是否传到了挂载目录。
2. 容器里看的路径是否就是挂载点。
3. 文件是否实际上传到了别的目录。

## 服务访问不到怎么办

优先检查：

1. 服务是否监听 `0.0.0.0`。
2. 使用的是不是分配给你的映射端口。
3. 容器内监听端口是否与映射规则一致。

## GPU 看不到怎么办

优先检查：

1. 容器分配时是否启用了 GPU。
2. `nvidia-smi` 是否可运行。
3. 当前镜像环境是否满足 CUDA 需求。

## 重建后环境变化怎么办

这通常是正常现象，因为容器系统层可能变化。

先确认：

1. 重要数据是否仍在挂载目录。
2. 是否在重建前做过手动备份镜像。
3. 是否更换了基础镜像。

## 资源不够怎么办

不要自己猜平台故障，建议直接联系分配员说明：

1. 你的容器名。
2. 当前资源限制。
3. 具体报错或瓶颈表现。
4. 需要增加什么资源。
5. 是短期需求还是长期需求。
