# DockerHub Manager 文档中心

## 文档定位

本文档集为 DockerHub Manager 平台的正式操作手册，面向以下两类用户：

**分配员（Allocator）**

负责容器资源分配、资源配额调整、镜像管理及 GPU 额度监督等平台运维工作。

**普通用户（End User）**

使用平台分配的 Docker 容器环境进行软件开发、模型训练、调试及服务部署。

!!! note "阅读路径"
    平台管理人员应优先阅读《分配员手册》。  
    容器使用者应优先阅读《用户手册》。

## 使用边界

本文档站点仅提供操作指南，不包含以下内容：

- 管理员凭证及密码
- Agent Token 敏感信息
- 宿主机系统配置细节
- 生产环境恢复相关的敏感命令

## 文档维护规范

正式文档应遵循以下原则：

1. 结论先行，细节后置
2. 面向实际操作场景，避免研发过程记录
3. 优先覆盖高频操作与高频问题
4. 文档中的截图、路径、端口说明应与当前系统实现保持一致
