# DockerHub Manager 文档中心

## 文档用途

本页面是 DockerHub Manager 的正式操作文档入口，面向以下两类对象：

1. 分配员
- 负责分配容器、调整资源、管理镜像、监督 GPU 额度。

2. 普通用户
- 使用平台分配的 Docker 容器进行开发、训练、调试和服务部署。

!!! note "阅读建议"
    如果你负责平台日常管理，请先看“分配员手册”。  
    如果你是容器使用者，请先看“用户手册”。

## 文档入口

### 分配员

- [分配员手册](allocator/index.md)

适合阅读的场景：

1. 新接手平台日常运维。
2. 需要给用户分配新容器。
3. 需要调整资源、重建容器或管理镜像。
4. 需要监督 GPU 用量和处理超额情况。

### 普通用户

- [用户手册](user/index.md)

适合阅读的场景：

1. 第一次使用平台分配的 Docker 开发环境。
2. 需要了解挂载目录、文件传输、端口映射和 GPU 使用方式。
3. 需要理解与过去宿主机直接开发的区别。

### GPU 用量说明

- [GPU 用量说明](gpu/index.md)

适合阅读的场景：

1. 需要理解“本周已用 / 有效额度”的含义。
2. 需要查看最近 30 天排行与曲线的解释。
3. 需要使用对外 GPU 用量门户。

### 常见问题

- [FAQ](faq/index.md)

适合阅读的场景：

1. 登录不上容器。
2. 文件传了但容器里看不到。
3. 服务端口访问不到。
4. GPU 不可见或环境异常。

## 使用边界

本网站只提供操作文档，不提供以下内容：

1. 管理员密码。
2. Agent Token。
3. 宿主机敏感配置细节。
4. 生产环境恢复中的敏感命令。

## 文档维护原则

正式文档应满足以下原则：

1. 先写结论，再写细节。
2. 面向实际操作，不写研发过程口语化记录。
3. 优先覆盖高频操作和高频问题。
4. 文档中的截图、路径、端口说明应和当前系统实现一致。
