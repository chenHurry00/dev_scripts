# 图片目录说明

本目录用于正式文档站的截图和图示资源。

建议约定：

1. `allocator/`
- 分配员操作截图

2. `user/`
- 用户使用截图

3. `common/`
- 通用页面、公共结构图

建议文件命名：

1. 使用小写英文或拼音。
2. 使用短横线分隔。
3. 不使用空格。
4. 不使用中文文件名。

示例：

```text
allocator-create-container.png
allocator-gpu-accounting-table.png
user-port-mapping.png
user-workspace-upload.png
```
