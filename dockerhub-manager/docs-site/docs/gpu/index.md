# GPU 用量说明

## 适用范围

本文档适用于：

- 分配员
- 需要查询个人 GPU 用量的普通用户

## 页面总览

GPU 计算时页面集中展示以下信息：

- 本周已用
- 有效额度
- 本周超额量
- 最近 30 天 GPU 卡时排行
- 每个用户的最近 30 天曲线入口

## 统计对象

平台统计 GPU 实际计算占用情况，而非"容器可见 GPU 数量"。

统计内容包括：

- GPU 卡时
- 低效占用卡时
- 当前活跃 GPU 数量
- 最近 30 天用量排行
- 单用户最近 30 天曲线

## 用户统计口径

用户聚合口径优先按以下标识：

1. 使用者标识

若容器未设置使用者标识，则退回至：

2. 容器登录用户

因此，对于分配员：

同一实际用户应保持同一使用者标识，避免随意变更。

## 本周已用 / 有效额度

例如显示：

```text
2.36 h / 144 h
```

含义为：

**2.36 h**

- 本周已累计使用的 GPU 卡时

**144 h**

- 当前生效的本周有效额度

有效额度通常由两部分组成：

- 基础额度
- 临时额度

在列表页中，该字段通常显示为：

```text
本周已用 / 有效额度
```

因此管理员和用户均可快速判断当前是否接近上限。

## 本周超额量

若本周已用超过有效额度，将产生超额量。

例如：

```text
本周已用 150 h
有效额度 144 h
本周超额量 6 h
```

若未超过额度，则超额量为 `0 h`。

## 最近 30 天用量

最近 30 天排行按以下口径统计：

- 按最近 30 天累计 GPU 卡时排序

需注意：

- 排行中的"30 天 GPU 卡时"为 30 天窗口统计
- 其中展示的"本周已用 / 有效额度"和"本周超额量"仍按本周口径计算

两种口径不应混淆。

可理解为：

- 排行为 30 天窗口的横向比较
- 额度和超额量为本周窗口的纵向约束

## 低效占用

低效占用大致表示：

- GPU 利用率不高
- 显存仍处于明显占用状态
- 持续达到统计条件

通常意味着：

- 任务空跑
- 程序挂起但未退出
- 使用方式不够合理

对分配员而言，这是需要重点关注的信号。

- 最近 30 天每日曲线
- 本周已用、有效额度、超额量
- 按服务器统计
- 按容器统计
- 临时额度记录

## 对外门户

对外门户通常使用专属链接访问。

门户特性：

- 用户本人可查看个人完整数据
- 其他用户仅显示脱敏名
- 门户为只读页面，不提供管理操作

门户适用于：

- 用户自行查看用量变化
- 分配员减少重复答疑

门户与后台管理页的核心统计口径一致，但权限不同：

- 门户为只读
- 后台可调整额度、重置链接、导出 CSV
- 门户中其他用户将进行脱敏显示

## 基础额度

基础额度适用于长期、稳定的需求。

常见场景：

- 某个课题组成员长期每周均需较高训练时长
- 某个用户长期承担持续推理或调参工作

管理员可在基础额度弹窗中覆盖默认值，如图 6 所示。

![基础额度设置](../assets/images/admin/11-gpu-base-quota-modal.png)

**图 6** 基础额度设置

建议：

- 长期稳定需求使用基础额度解决
- 避免长期需求依赖临时额度

## 临时额度

临时额度适用于短期突发需求，例如：

- 近期集中跑实验
- 临近汇报或论文截稿
- 临时借用更多 GPU 时间

管理员可设置：

- 临时额度大小
- 生效周数
- 随时重置为 0

图 7 所示为临时额度设置弹窗。

![临时额度设置](../assets/images/admin/12-gpu-temp-quota-modal.png)

**图 7** 临时额度设置

因此有效额度可理解为：

```text
有效额度 = 基础额度 + 当前仍在生效期内的临时额度
```

## 分配员使用建议

建议重点关注：

- 本周已明显超额的用户
- 最近 30 天排行长期靠前的用户
- 长时间低效占用 GPU 的用户
- 短期集中高负载但有正当需求的用户

处理方式通常分为两类：

- 长期需求调整基础额度
- 短期需求发放临时额度

实际工作中，建议每周至少执行一次检查：

- 查看本周超额用户
- 查看最近 30 天排行前列用户
- 查看是否存在长期低效占用
- 对确有需要的用户补充临时额度或调整基础额度

## 普通用户使用建议

普通用户主要关注：

- 个人本周用量
- 是否接近额度上限
- 最近 30 天用量变化是否正常

若发现近期需要明显更多 GPU 资源，应尽早联系分配员，避免等到超额后再处理。

## 总结

**普通用户重点关注**

- 本周已用
- 有效额度
- 最近 30 天趋势

**分配员重点关注**

- 排行
- 低效占用
- 基础额度与临时额度合理性
